# Marcio Wendell

Desenvolvedor com foco em backend. Busco vagas de **backend ou fullstack**.

## Backend

- **bioquest** *(em breve)*: API em TypeScript com Effect e PostgreSQL. Organizada em camadas com erros de domínio tipados, OpenAPI, testes E2E, testes de mutação (Stryker) e CI.
- [**mwdx**](https://github.com/wenderu00/mwdx): monorepo TypeScript (CLI + SQLite/Drizzle + dashboard Next.js) que analisa meus repositórios. Os contratos em Zod geram os JSON Schemas, e os achados são reconciliados entre execuções.
- [**familia_em_ritmo**](https://github.com/wenderu00/familia_em_ritmo): API Spring Boot / Java 17 com JPA e springdoc, organizada em application/domain/infra, com um DTO por caso de uso. O front é em Flutter.

## Ferramentas com Claude Code

- **requisitos-pipeline** *(em breve)*: pipeline de 6 subagentes que transforma texto livre em requisitos estruturados, com validação por schema e evals.
- [**padrao-digital-pe**](https://github.com/wenderu00/padrao-digital-pe): plugin que gera páginas Next.js no Design System do Governo de Pernambuco, com guardrails determinísticos e evals.

## Front / jogos

- [**the-galadur**](https://github.com/wenderu00/the-galadur): jogo em React com a engine separada da UI, feita de regras de domínio puras e testadas. [Jogar](https://wenderu00.github.io/the-galadur/).
- [**XPomodoro**](https://github.com/wenderu00/XPomodoro): timer de sessões pomodoro em React + Vite + Tailwind, com o armazenamento das sessões isolado atrás de uma porta (`ISessionRepository`).
